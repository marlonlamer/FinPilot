## 📌 Overview

**FinPilot** is a full-stack personal finance tracking application that helps users manage their finances efficiently by tracking income, expenses, savings, and budgets in one centralized platform.

The project aims to provide a clean, user-friendly, and responsive experience while helping users gain better financial awareness through real-time financial monitoring.

> 🚧 **Project Status:** Actively being developed and improved.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/finpilot.git
cd finpilot
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```
